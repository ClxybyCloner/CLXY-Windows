## ⚡ نصب در Windows

1. **نصب‌کننده** را از [بخش دانلود](#-download) بالا دانلود کنید.
2. پیش از اجرای آن، **SHA-256 آن را تأیید کنید** ([روش انجام در پایین](#-verify-your-download)).
3. آن را **باز کنید** و مراحل را دنبال کنید (نصب برای هر کاربر). اگر SmartScreen ظاهر شد، ابتدا [یادداشت‌های امنیتی](#-windows-security-warnings) را بخوانید.
4. **CLXY را اجرا کنید**، از نصب‌کننده یا منوی Start.
5. پیش از ورود یا اتصال، [CLXY چیست](#-what-clxy-is) را بخوانید.

برنامه در `%LOCALAPPDATA%\Programs\CLXY` نصب می‌شود و داده خصوصی حساب، تنظیمات و لاگ‌ها را در پوشه `user-data` کنار خود نگه می‌دارد. این پوشه را خصوصی در نظر بگیرید.

### 📦 نسخه قابل‌حمل

ساخت قابل‌حمل همچنان v1.0.11 است. v1.0.14 شامل ZIP قابل‌حمل جدیدی نیست. از [دانلود قدیمی‌تر](#-download) استفاده کنید، هش آن را بررسی کنید، پوشه `CLXY` را استخراج کنید و `clxy.exe` را اجرا کنید. پوشه را قابل‌نوشتن نگه دارید. برنامه `user-data` خصوصی خود را درست کنار فایل اجرایی ذخیره می‌کند.

- نصب‌کننده **بدون امضا** است. آزمایش نصب موفق، اعتبار SmartScreen یا هویت ناشر را ثابت نمی‌کند.

## 🔄 به‌روزرسانی‌ها چگونه کار می‌کنند

CLXY پس از هر اتصال موفق VPN، **از جمله اتصال‌های مجدد**، آخرین انتشار پایدار این مخزن را بررسی می‌کند. وقتی ساخت جدیدتری پیدا شود، برنامه اعلانی با دکمه **دانلود** نشان می‌دهد. نسخه‌های نصب‌شده نصب‌کننده را دریافت می‌کنند. آخرین ZIP قابل‌حمل v1.0.11 است و v1.0.14 بسته قابل‌حمل جدیدتری ندارد.

دانلود و نصب همیشه انتخاب *شما*ست: **CLXY هرگز به‌صورت خودکار به‌روزرسانی‌ها را نصب نمی‌کند.**

<a id="-what-clxy-is"></a>

## 🧭 CLXY چیست

CLXY یک کلاینت دسکتاپ مستقل و غیررسمی برای Windows است. این برنامه از رابط Flutter و یک هسته Go همراه استفاده می‌کند که به‌صورت محلی اجرا می‌شود و از طریق loopback با برنامه ارتباط دارد. بسته شامل رابط ورود و راه‌اندازی، یکپارچه‌سازی دسکتاپ و اعلامیه‌های حقوقی لازم ([`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md)، [`LICENSE`](LICENSE)) است.

### رابط Flutter و هسته شبکه Go

کلاینت Windows برای رابط دسکتاپ خود از Flutter استفاده می‌کند و یک فرایند همراه Go را برای شبکه اجرا می‌کند. برنامه هسته را از طریق API محلی loopback کنترل می‌کند و هسته یک پروکسی محلی SOCKS5/HTTP ارائه می‌دهد. برای اتصال‌های خروجی، از HTTP/2 CONNECT رمزگذاری‌شده روی TCP و HTTP/3 CONNECT روی QUIC پشتیبانی می‌کند و اگر اتصال HTTP/3 برقرار نشود، به HTTP/2 برمی‌گردد.

```text
Flutter desktop UI
  └─ local loopback API → Go core
       ├─ local SOCKS5 / HTTP proxy
       └─ HTTP/2 CONNECT over TCP or HTTP/3 CONNECT over QUIC
```

CLXY یک کلاینت مستقل و شخص ثالث است؛ دسترسی به حساب و سرویس بالادستی به وابستگی‌های خارجی نیاز دارد. انتشار این نصب‌کننده **حسابی ارائه نمی‌کند و دسترسی به سرویس را تضمین نمی‌کند.** پروکسی بالادستی فقط روی پورت‌های وب TCP یعنی **80، 443، 8080 و 8443** کار می‌کند. برنامه‌های وابسته به UDP و پورت‌های دیگر ممکن است کار نکنند. صرفاً به این دلیل که برنامه دسکتاپ باز است، فرض نکنید ترافیک همه برنامه‌ها محافظت می‌شود.

## مسیریابی پیشرفته VPN

در این معماری، از ترکیب فناوری Xray و زیرساخت Mozilla VPN برای ایجاد یک مسیر ارتباطی چندلایه استفاده میشود. هدف، افزایش انعطافپذیری در مدیریت ترافیک، جداسازی مسیرهای ارتباطی و کنترل دقیقتر ترافیک ورودی و خروجی است.

ویژگیها:

* مسیریابی چندلایه: ایجاد زنجیره ارتباطی میان لایه ورودی و خروجی VPN.
* یکپارچهسازی Mozilla VPN: استفاده از زیرساخت WireGuard برای مدیریت مسیر خروجی.
* مسیریابی هوشمند: امکان هدایت ترافیک بر اساس سیاستهای تعریفشده.
* مدیریت تونل اختصاصی: کنترل مستقل مسیر ارتباطی و وضعیت تونل خروجی.
* محافظت از IP: جلوگیری از افشای آدرس IP اصلی در شرایط قطع تونل.
* مدیریت خطا و بازیابی: پیشبینی سازوکارهای کنترل اتصال و بازیابی مسیر ارتباطی.

ساختار ارتباطی:

VLESS → Xray Core → Linux Routing → Mozilla VPN → Internet

این ساختار با هدف ایجاد یک زیرساخت ارتباطی منعطف، قابل توسعه و قابل مدیریت طراحی شده است.

## ❓ پرسش‌های متداول

**آیا کد منبع اینجاست؟**
این مخزن شامل دانلودهای انتشار و مستندات است. انتشار v1.0.14 یک آرشیو جداگانه GPLv3 فقط برای کد منبع هسته Go دارد. این آرشیو برنامه قابل‌نصب نیست و رابط Flutter یا پروژه نصب‌کننده را شامل نمی‌شود.

**نصب‌کننده یا نسخه قابل‌حمل؟**
برای نصب معمولی از نصب‌کننده استفاده کنید (ورودی منوی Start و نصب برای هر کاربر). اگر می‌خواهید پوشه را همراه خود جابه‌جا کنید یا بدون نصب اجرا کنید، نسخه قابل‌حمل مناسب است. ZIP قابل‌حمل موجود v1.0.11 است.

**تنظیمات من کجا هستند؟**
در پوشه `user-data` کنار برنامه، چه نصب‌شده و چه قابل‌حمل. اگر برایتان مهم است، از آن پشتیبان بگیرید.

**Windows 7 / 8 / ARM؟**
پشتیبانی نمی‌شود. هدف **Windows 10/11 روی x64** است. این انتشار بسته ARM64 یا 32 بیتی ندارد.

**داشبورد در پنجره کوچک فشرده به نظر می‌رسد.**
هنگام تغییر اندازه، چیدمان دسکتاپ را حفظ می‌کند. برای بزرگ‌نمایی <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>−</kbd> را فشار دهید.

**نسخه‌های قدیمی‌تر؟**
در [صفحه انتشارها](https://github.com/ClxybyCloner/CLXY-Windows/releases) باقی می‌مانند و چک‌سام‌هایشان در [`CHECKSUMS.txt`](CHECKSUMS.txt) قرار دارد.
