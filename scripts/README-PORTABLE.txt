CLXY برای Windows x64

برای اجرا، CLXY-Portable.cmd را باز کن. تنظیمات و حساب‌هایی که خودت اضافه می‌کنی در پوشهٔ user-data کنار برنامه می‌مانند.

حالت TUN ممکن است برای نصب سرویس Windows ازت اجازهٔ مدیر سیستم بخواهد. حالت‌های Proxy و System proxy به آن سرویس نیاز ندارند.

این بسته حساب یا اطلاعات ورود ندارد.
